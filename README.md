# Adam the Dealmaker — Site estilo Windows XP

Site pronto pra publicar de graça no GitHub Pages.

## Como publicar (5 minutos)

1. Acesse [github.com](https://github.com) e crie uma conta (se ainda não tiver).
2. Clique em **New repository** (botão verde).
   - Nome sugerido: `adam-the-dealmaker` (pode ser outro nome, sem espaços).
   - Marque como **Public**.
   - Não marque "Add a README" (já temos um).
   - Clique em **Create repository**.
3. Na página do repositório recém-criado, clique em **uploading an existing file** (ou "Add file → Upload files").
4. Arraste o arquivo **`index.html`** para lá (é o único arquivo que precisa subir).
5. Clique em **Commit changes** (pode deixar a mensagem padrão).
6. Vá em **Settings** (aba do repositório) → **Pages** (menu lateral esquerdo).
7. Em "Build and deployment" → "Source", selecione **Deploy from a branch**.
8. Em "Branch", selecione `main` e a pasta `/ (root)`, depois **Save**.
9. Espere ~1–2 minutos. Atualize a página — vai aparecer um link assim:
   `https://SEU-USUARIO.github.io/adam-the-dealmaker/`

Esse é o link direto do seu site, sem custo nenhum.

## Se quiser atualizar o site depois

Sempre que editar o `index.html`, volte no repositório, clique em **Add file → Upload files**
de novo, suba a versão nova (ela substitui a antiga) e faça commit. O link continua o mesmo.

## Alternativa ainda mais rápida (sem conta GitHub)

Se quiser publicar sem nem criar repositório:

1. Acesse [app.netlify.com/drop](https://app.netlify.com/drop)
2. Arraste a pasta com o `index.html` para a área indicada
3. Pronto — gera um link tipo `nome-aleatorio.netlify.app` na hora

Dá pra usar as duas opções em paralelo, sem problema.
